# Порядок — реєстр порушень ПДР

Навчальний вебзастосунок для варіанта 13. Обидві умови об'єднані в один підсумковий сайт для обліку порушень правил дорожнього руху працівниками поліції.

## Можливості

- Реєстр справ із пошуком за номером справи, адресою, водієм або номером автомобіля.
- Фільтри за інспектором, статтею порушення та статусом справи.
- Повний цикл роботи зі справою: створення, перегляд, редагування й видалення.
- Довідники інспекторів, транспортних засобів і статей із додаванням, зміною та видаленням записів.
- Зв'язок однієї справи з кількома інспекторами та кількома статтями порушень.
- Обчислення загальної суми штрафу за статтями справи.
- Локальна SQLite база з демонстраційними даними. Всі імена, номери справ і автомобілі в початкових записах вигадані.

## Запуск

Потрібен .NET 8 SDK. У PowerShell з каталогу `purch` запустіть:

```powershell
dotnet run --project .\traffic-violation-register\TrafficRegister.csproj --urls http://localhost:5080
```

Відкрийте `http://localhost:5080`. Під час першого запуску застосунок створює SQLite базу `App_Data/traffic-register.db` і додає демонстраційні записи. Щоб почати з чистими даними, зупиніть сайт і видаліть цей файл: під час наступного запуску база створиться повторно.

## Структура

- `Models/` — сутності та моделі форм.
- `Data/` — контекст Entity Framework Core і демонстраційні дані.
- `Controllers/` і `Views/` — логіка MVC та сторінки.
- `wwwroot/` — стилі й скрипти.
- `App_Data/` — локальна база даних, не включена до Git.

Реалізація використовує ASP.NET Core MVC 8, Entity Framework Core та SQLite. Умови орієнтовані на ASP.NET MVC 5; тут застосовано сучасний варіант тієї самої архітектури MVC. Один звіт для обох робіт розміщено в `../Report_variant13.txt`.
